## Installation
- Check environment on command prompt, like php (git -v), composser (composer -v), git (git -v)
- after check n if u dont have laravel, install laravel heard on ur browser
- check on terminal/command prompt again, if u already download laravel heard
- if u already have php n everything u need on this project, just create folder for ur project laravel on ur computer
- input command (composer create-project laravel/laravel belajar-laravel) on ur terminal n then just adjust for ur folder name project
- input cd library-system (adjust on ur folder name project)
- and then input (php artisan serve)
- open ur vscode, n then open folder like ur project name folder
- n then u can create folder on phpmyadmin for database ur project (adjust ur name project)
- n then u can check on vscode file like name (.env) just chec for db connection
- delete n adjust like name folder on ur database that you made previously
- n then u can open terminal again, n type like (php artisan migrate) so that the database tables appear immediately
- To be sure, you can re-type the command to open the Laravel browser, like (php artisan serve)
- after all, u can open vscode n create new terminal
- just check n type like (git status) n then if fatal u can just type (git init) 
- n then (git add .)
- just check again (git status) n if work u can commit (git commit -m “first commit - init laravel”)
- n then u can open github n create repository, in accordance with ur project name folder
- n then u can adjust for repository to integrate VS Code with GitHub (like changing master to main on branch)
- n boom u already have ur code integrate to github n u can make project with ur team
